Margin and Padding Practice

Este ejercicio forma parte del módulo Block and Inline dentro de CSS Foundations.
Su objetivo principal es practicar cómo funcionan las propiedades padding y margin, y cómo afectan a la posición, separación y tamaño de los elementos de bloque (div).

⸻

🧠 ¿Qué es padding?

El padding es el espacio interior de un elemento:
📌 El espacio entre el borde del elemento y su contenido.
[Borde del div]
|  padding  |
(texto)
Aumentar el padding → hace que el div se vuelva más grande hacia dentro, creando más espacio alrededor del texto o contenido.

⸻

🧠 ¿Qué es margin?

El margin es el espacio exterior de un elemento:
📌 El espacio entre el borde del div y los otros elementos de la página.
